# New hire onboarding

Welcome to the team. Complete these steps in your first **30 days**.

## Week 1

1. Read `docs/api-auth.md` before calling any internal API.
2. Set up LM Studio locally for agent harness development.
3. Pair with your buddy on the research assistant project.

## Week 2

- Run through `docs/deploy-runbook.md` in staging (never prod on day one).
- File your first PR against `section_2/` lessons.

## Questions

If policy questions come up, check `docs/refunds-policy.md` before escalating to finance.
